Discord Rich Presence Settings

General

Globally enables or disables Rich Presence updates to Discord clients.
A numeric ID that tells Discord which application to show in your profile (name, icon, artwork).

How to get it:
  1. Open the Discord Developer Portal and sign in.
  2. Click New Application, give it any name (e.g. Jellyfin), and confirm.
  3. On the application page, copy the Application ID (under “General Information”).
  4. Paste it in the field above and save.
The ID is a 17–19 digit number. You can also upload a custom icon in the Developer Portal — it will appear as the large image in your Discord activity.
Interval between session state inspections. Recommended: 5 seconds. Lower values do not increase Discord update frequency due to internal rate-limiting.
Publicly reachable HTTPS/HTTP address of this Jellyfin server. Required for Discord to display media artwork from your library. If omitted, a Jellyfin fallback icon is shown instead.

👤 User Filter (Multi-User Servers)

By default the plugin reports the first active session it finds on the server. On a shared server (e.g. with family or friends), this means that if someone else starts watching something, their playback will immediately replace your Discord activity — even while you are already watching something yourself.

Setting a filter here locks the presence to your account only. Any session belonging to a different user is completely ignored.
Enter either your Jellyfin username (e.g. Admin) or your User ID (a UUID like a1b2c3d4-e5f6-…).
To find your User ID: open your Jellyfin dashboard → Administration → Users, click your user, and copy the ID from the page URL (…/users/<your-id>/edit).

Leave blank to report the first active session on the server (single-user setups).

When enabled, your Discord activity shows a paused badge and icon instead of disappearing immediately. After the grace period below, the activity is removed automatically.
