Discord Rich Presence Settings

General

Globally enables or disables Rich Presence updates to Discord clients.
The Client ID of your Discord Application from the Discord Developer Portal.
Interval between session state inspections. Recommended: 5 seconds. Lower values do not increase Discord update frequency due to internal rate-limiting.
Publicly reachable HTTPS/HTTP address of this Jellyfin server. Required for Discord to display media artwork from your library. If omitted, a Jellyfin fallback icon is shown instead.

👤 User Filter (Multi-User Servers)

On shared servers with friends or family, another user's playback can overwrite your Discord activity. Enter your Jellyfin username (e.g. Admin) or your exact User ID (UUID) to restrict Rich Presence to your sessions only. Leave blank to use the first active session on the server.

⏸️ Pause Behaviour

When enabled, your Discord activity shows a paused badge and icon instead of disappearing immediately. After the grace period below, the activity is removed automatically.
How long (in minutes) the paused activity stays visible in Discord before being cleared. Set to 0 to clear immediately (classic behaviour). Requires "Show Paused State" to be enabled.
